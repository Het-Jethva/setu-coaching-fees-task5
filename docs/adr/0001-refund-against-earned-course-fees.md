# Calculate refunds against earned course fees

Calculate earned fees from the discounted course total and calendar days used, including the withdrawal day. Refund only collections above earned fees, cancel unearned charges, and preserve any unpaid earned fees. This separates a student's payment schedule from the value of the course already used, so an unpaid instalment does not accidentally become a cash refund or disappear when the student withdraws. The user accepted this demo policy on 3 November 2026 because the assignment supplies no client-specific formula.
